# Harvey Breaux — portfolio

A custom static portfolio with interactive system views, scroll reveals, expandable experience, a printable résumé, and a Markdown content source. No runtime dependencies or package installation required.

## Local preview

Requires Node.js 22 or newer.

```sh
npm run dev
```

Open http://127.0.0.1:4173. The server builds on startup. After editing content or source, run `npm run build` and refresh the page. Use `PORT` to choose a different port if needed.

## Update content

Edit `content/resume.md`, then run:

```sh
npm run build
npm run check
```

See `AGENTS.md` for editorial and agent instructions. The homepage and printable résumé read facts from Markdown. Design copy and illustrative diagrams live in `src/`; update those if a change in professional focus makes them outdated. Featured-work entries record the approved top three and order. Instructions require proposing a new selection to Harvey when relevant, rather than fixing any permanent lead project.

The Markdown format uses `##` section headings, `###` entry headings, metadata lines in `- Key: value` form, ordinary accomplishment bullets, and plain-text paragraphs. It intentionally supports this small documented subset rather than arbitrary Markdown syntax. Content is HTML-escaped during the build.

## GitHub Pages

The site is prepared for GitHub Pages but has not been published. When ready:

1. Create a repository, ideally `hbreauxv.github.io` for the root profile URL, and push this project's contents with `main` as the default branch.
2. In repository Settings → Pages, select **GitHub Actions** as the build/deployment source.
3. Push to `main` or run **Publish portfolio** manually. The workflow builds, checks, and deploys `dist/`.

A differently named repository also works; all local asset URLs are relative. The default free Pages route uses a public repository, so keep the Markdown and any future assets suitable for public viewing. A custom domain can be connected later.

## Project map

- `content/resume.md` — public professional facts and selected projects
- `src/index.html` — page structure and editorial headline copy
- `src/styles.css` — responsive visual design and motion preferences
- `src/app.js` — keyboard-accessible diagram tabs and progressive enhancement
- `scripts/build.mjs` — Markdown-to-HTML build, validation, and output escaping
- `scripts/check.mjs` — output integrity and content checks
- `dist/` — generated deployment files (ignored by Git)
- `.github/workflows/pages.yml` — GitHub Pages deployment

Use the résumé page's **Print / Save PDF** button for a PDF generated by the browser. This is a printable HTML résumé, not a pre-generated PDF download.
